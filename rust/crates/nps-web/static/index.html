    说明

    登录方式

    可使用管理员分配的用户名与密码登录；仅查看自己隧道的客户端账号看不到站点与证书入口。也可展开登录页下方的「使用管理员令牌」，输入服务端环境变量 NPS_ADMIN_TOKEN。令牌只保存在当前浏览器会话（sessionStorage），关闭标签页即清除。

    数据与安全

    页面不加载任何 CDN、外部字体或统计脚本，所有请求只发往当前管理服务；登录凭据只提交给当前管理服务，不会写入页面或日志。页面每 3 秒自动刷新一次状态。
