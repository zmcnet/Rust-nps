说明

管理令牌

首次部署时，在启动服务前设置环境变量 NPS_ADMIN_TOKEN（至少 24 字节，可见 ASCII，不含空格）。本页面不提供默认密码，令牌只保存在当前浏览器会话（sessionStorage），关闭标签页即清除。

数据与安全

页面不加载任何 CDN、外部字体或统计脚本，所有请求只发往当前管理服务；所有 API 都需要 Bearer 令牌，且不接收 Cookie。页面每 3 秒自动刷新一次状态。
